I work at Igalia, a consultancy implementing cool features in many foundational
open source projects. My team focuses on standardizing JavaScript features and
implementing them in browsers.

This is a list of features I'd love to be hired to work on, as they sit in the intersection of "things I personally
find cool" and "things that would be valuable for the JavaScript ecosystem":

- Module declarations, a TC39 proposal to allow definfing multiple JS modules in a single file. This would greatly simplify
  bundlers, by making it possible to rely on the built-in implementation of JS modules that all browsers already have.
- Fixing top-level await in Safari: top-level await has been part of JS for years, but Safari bugs still make it difficult
  to rely on it in production.
- Adding support for import maps in web workers. Import maps allow easy remapping of modules on the web, allowing "bare
  specifiers" for importing libraries like we are used to on non-web environments. Unfortunately they only work on the
  main document page, and not in any type of worker.
